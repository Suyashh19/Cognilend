## Slides (12)

**1. Title**
- CogniLend: hybrid rule-and-ML loan decisioning
- WCE Sangli, Apni Leap AY 2026-27; guide Dr. V. N. Waghmare; groups G10 / G12 / G15

**2. Problem**
- Lenders must give a written, true reason for every decision and must not discriminate
- Black boxes are accurate but unexplainable; rule systems cannot rank compliant applicants

**3. Our answer: four layers**
- Rules first (HARD reject / SOFT review) -> constrained tree + Bayesian confidence -> hash-chained audit DB with approval lock -> disparate-impact audit
- Output: Approved / Rejected / Human Review + confidence + reason + audit-log ID

**4. Data**
- Seeded synthetic Indian dataset, 10,000 rows, documented defects
- Label from latent repayment risk, not the rules (rules alone: 0.742 accuracy)
- Loan.csv: label likely "default / not priced"; file not available, kept as secondary benchmark

**5. Rule engine**
- Forward chaining over derived facts (FOIR, LTV, age at maturity...)
- 7 HARD + 4 SOFT rules, each with rationale and source; rule-trigger precision checked against an independent implementation

**6. Interpretable model**
- Entropy tree: depth 4, 15 nodes, uses CIBIL, FOIR, experience
- Val acc 0.7827 (target 0.80, missed); test 0.7930; gap 0.0232
- Ensembles 0.8674-0.8681 on test: the price of a readable path

**7. Confidence and routing**
- Beta(1,1) leaf posterior; Brier 0.1578
- τ = 0.70: 60.5% auto at 0.8893; routed cases only 0.6455 accurate

**8. Integrated results**
- 1478 test applications: 1478 logged, 69.9% automatic
- Three fresh-DB runs identical
- Lock: 500 concurrent requests -> exactly one approval per collateral

**9. Fairness**
- Gender passes the four-fifths rule
- Age band fails (lowest 0.366): from age-linked rules and the label, not the model
- Protected-blind mitigations tried; decision on the rules is pending

**10. Live demo**
- Seven cases: HARD reject, auto-approve, auto-reject, SOFT review, low confidence, duplicate collateral, malformed input

**11. Testing**
- 314 automated tests, 314 passing; all 7 evidence gates
- KPI report generated from code; two KPIs honestly missed

**12. Limitations and next steps**
- Accuracy and age-DI KPIs; Loan.csv; PostgreSQL; calibrate the advisory stress twin
