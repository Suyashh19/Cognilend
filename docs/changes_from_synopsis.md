# Changes from the synopsis

Generated by `python scripts/build_docs.py`. An honest list of where the delivered system differs from the signed synopsis and the project brief, and why.

| # | Area | Synopsis / brief | Delivered | Reason |
|---|---|---|---|---|
| 1 | Dataset | Loan.csv as the data source (team notebook) | Seeded synthetic Indian dataset is primary; Loan.csv kept as a secondary benchmark only | Loan.csv was not available to this build, and its `status` target most likely means default / not priced, not approval. The synthetic set matches the rule engine (CIBIL, FOIR, LTV) and has a documented generator. |
| 2 | Label | Historical approval | Label from a latent repayment-risk score + noise; rules not used | Otherwise the ML layer would only re-learn the rules (the team file rejected ~96 % of rule violators). |
| 3 | Split | 70 / 30 | 70 / 15 / 15 (train / validation / test), stratified, seed 42 (train 6,892) | The 30 % is split into validation (tuning) and test (scored once), so no number is tuned on the test set. |
| 4 | Prototype model | XGBoost (legacy prototype), 80/20 split, seed 0 | Constrained entropy tree; XGBoost only as a benchmark; seed 42 everywhere | Synopsis requires depth <= 4 and <= 15 nodes with a traceable path. |
| 5 | Rules | R1-R7 all hard; age at maturity 60 (salaried) / 65 (self-employed) | 7 HARD (incl. a new fraud-registry rule R02), single maturity cap 65 (R03), work experience moved to SOFT (S02), borderline FOIR (S03) and missing information (S04) as SOFT | Experience shortfall is not disqualifying on its own; a single documented cap; see docs/rule_justification.md. |
| 6 | Protected attributes | Gender excluded from the model | Gender, marital status and age band excluded; Age and age-at-maturity also kept out of the model; property area excluded as a possible proxy | Age band is protected; age at maturity carries age. |
| 7 | Live input repairs | (not specified) | Sign-error and tenure-in-years repairs only for historical data; live input is validated and rejected if invalid | A real 24-month home loan must not be rescaled. |
| 8 | KPI: validation accuracy >= 80 % | Met | **Missed: 0.7827** | Depth / node caps bind; caps were not loosened. Ensembles reach 0.8639. |
| 9 | Routing target (brief: e.g. 90 % auto accuracy) | 90 % | **0.8893 at 60.5% auto (test)**, τ = 0.70 | 90 % is not reachable with an 8-leaf tree while keeping the majority auto-cleared. |
| 10 | NFR: DI >= 0.80 | All subgroups | **Missed: lowest 0.366 (age_band = <=25)** | Caused by age-linked rules and the historical label, not the model; mitigations tried and listed in fairness.md; decision pending. |
| 11 | Tree image | Graphviz / dtreeviz | matplotlib (`tree.png`) + `tree.dot` | No Graphviz binary on the build machine. |
| 12 | Loan.csv label finding and benchmark | Reproduce and benchmark | **Not done** | File not supplied; tooling implemented and tested on a stand-in frame. |
| 13 | Database | PostgreSQL-compatible | SQLite in development; PostgreSQL trigger DDL included but untested | No PostgreSQL server available. |
| 14 | Python | 3.10+ | 3.11+ | Pinned pandas 3.x requires 3.11. |
| 15 | Optional SHAP comparison | Optional | Not done | Path contributions are exact for a single tree. |
| 16 | Stress twin | Optional | Implemented as an advisory page | Thresholds illustrative, to be calibrated. |
